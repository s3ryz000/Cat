# Name That Cat

A live, Kahoot-style quiz: 19 cats, four names each.

**Play:** https://s3ryz000.github.io/Cat/

1. Open the link on the projector or TV and click **Start hosting**.
2. Players scan the QR code (or open the link and type the 5-letter code) on their phones.
3. Press **Start game**. Enter moves to the next screen.

`Cat_Kahoot_Quiz.xlsx` has the same questions in Kahoot's spreadsheet import format.
